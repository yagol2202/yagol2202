### 📂 Principais Projetos

Aqui estão alguns dos projetos mais relevantes que desenvolvi para consolidar meu aprendizado:

#### 💈 [Barbearia](https://github.com/yagol2202/Barbearia) | Sistema de Agendamento Full Stack
* **Descrição:** Solução digital completa desenvolvida para automatizar e otimizar o fluxo de agendamentos em barbearias, melhorando a experiência do cliente e a gestão do estabelecimento.
* **Arquitetura do Projeto:** Dividido de forma modular em três ecossistemas independentes:
  * `backend`: API REST responsável pelas regras de negócio, persistência de dados e autenticação.
  * `frontend-cliente`: Interface responsiva onde os usuários finais realizam e gerenciam seus agendamentos de forma intuitiva.
  * `frontend-admin`: Painel administrativo focado na gestão do negócio, controle de horários, barbeiros e serviços.
* **Tecnologias utilizadas:** Node.js, Express, MySQL, React, JavaScript/TypeScript, CSS3 e HTML5.
* **Destaques técnicos:** 
  * Separação estrita de responsabilidades entre cliente e administrador utilizando aplicações front-end distintas integradas à mesma API.
  * Modelagem de banco de dados relacional para gerenciar horários, disponibilidade, profissionais e serviços sem conflitos de agenda.
* 🔗 [Acessar Repositório](https://github.com/yagol2202/Barbearia)


#### 👟 [DigitalStore](https://github.com/yagol2202/DigitalStore) | E-commerce Responsivo
* **Descrição:** Aplicação web de comércio, focada na experiência do usuário para uma loja de calçados. O sistema simula fluxos reais de navegação, vitrines de produtos e filtragem avançada de itens.
* **Tecnologias utilizadas:** React (Hooks avançados), React Router DOM (v6), Bootstrap 5, Bootstrap Icons e Vite.
* **Destaques técnicos:**
  * **Rotas Dinâmicas:** Criação de rotas inteligentes que capturam parâmetros de ID diretamente da URL (`/product/:id`) para renderizar os detalhes específicos de cada calçado de forma reativa.
  * **Componentização Modular:** Construção de componentes altamente reutilizáveis como o `<FilterGroup />` (filtros dinâmicos via checkbox/radio) e o `<ProductOptions />` (seletor de tamanhos e cores com estados customizados via Bootstrap).
  * **Gerenciamento de Estados:** Uso estratégico de React Hooks (`useState`, `useEffect`, `useParams`, `useSearchParams`) para controlar buscas textuais integradas diretamente à URL da aplicação.
* 🔗 [Acessar Repositório](https://github.com/yagol2202/DigitalStore)
